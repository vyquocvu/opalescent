# Architecture Decision Records

Create one file per accepted or proposed language decision: `NNNN-short-title.md`. Each should state: Status, context, precise rule, options rejected, semantic examples, observable performance consequences, safety obligations, conformance tests, compatibility, supersedes/superseded-by. Proposed ADRs are not normative until accepted.

First group: D001–D004 must be decided together in the initial ownership ADR.
